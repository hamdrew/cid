# Quickstart: personal use and feedback

Start with the [README](../../README.md):

- [Set up once](../../README.md#set-up-once).
- [Use it normally](../../README.md#use-it-normally).
- [Send bullet-point feedback or share material for review](../../README.md#give-feedback).
- [Try an optional check](../../README.md#optional-checks) when convenient.

No formal campaign, participant quota or scorecard is required. Agents may run the
model-free checks described in the README, but must never launch AI tools for testing.
The [constitution](../../.specify/memory/constitution.md) permits explicitly requested
review of shared artifacts in this conversation without extra model calls.
